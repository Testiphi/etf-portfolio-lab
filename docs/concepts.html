年化收益

（末值 / 首值）^(1/年数) - 1，年数按自然日折算

说明什么：把一段不等长的历史压缩成「每年赚多少」的口径，便于横向比较。

什么时候会骗人：它是**几何**平均，一定低于各年收益的算术平均；区间起点挪一年就可能差好几个百分点。看到年化收益时，必须先问「这是哪一段」。

年化波动率

日收益标准差 × √252

说明什么：衡量收益围绕均值摆动的幅度，是大多数风险指标的分母。

什么时候会骗人：它把上涨和下跌同等对待。对持续买入的定投来说，下跌其实是「打折」，所以单看波动率会高估定投的痛苦程度。

夏普比率

（年化收益 - 无风险利率）/ 年化波动率

说明什么：每承担一单位波动能换来多少超额收益。

什么时候会骗人：分子分母都依赖「无风险利率取多少」。用 1 年期国债和用 3 个月 Shibor，同一组合的夏普可能差出可观幅度；而且它假定收益近似正态，对尖峰厚尾的 A 股并不成立。

索提诺比率

（年化收益 - 无风险利率）/ 下行波动率

说明什么：只用下跌方向的波动作为风险，更贴近「我讨厌亏钱」的直觉。

什么时候会骗人：样本里下跌日很少时分母接近 0，数值会极度放大；所以必须同时看样本量和下行天数。

卡玛比率

年化收益 / |最大回撤|

说明什么：每承受一个单位的最大回撤能换到多少年化收益。

什么时候会骗人：分母是历史极值，所以它同样继承了最大回撤的全部敏感性——换一段区间，排名可能反转。

最大回撤

min（净值 / 历史最高净值 - 1）

说明什么：历史上最难受的一段：从高点到低点亏了多少，以及多久没回本。

什么时候会骗人：它是**单一历史路径上的极值**，对区间极度敏感。只报一个数字不够，至少要同时给出回撤最深的前几段与修复天数。

VaR（风险价值）

历史法：收益分布的 5% 分位；参数法：μ + σ·z

说明什么：在给定置信水平下，单个周期内「通常不会超过」的损失。

什么时候会骗人：它只描述分位点，**不告诉你超过之后会亏多少**；历史法在样本不足时低估尾部，参数法在厚尾数据上系统性低估。所以本项目总是把两种口径并排展示。

CVaR（条件风险价值）

收益落在 VaR 之外那部分的平均损失

说明什么：回答了 VaR 没回答的问题：真的跌破了，平均会亏多少。

什么时候会骗人：它依赖尾部样本数量。若历史上只出现过两三次极端下跌，这个数字本身就极不稳定。

XIRR（资金加权年化）

令 Σ 现金流 / (1+r)^(实际天数/365) = 0 的 r

说明什么：把定投每一笔钱的**实际在场时间**考虑进去后的真实年化收益。

什么时候会骗人：很多人用「总收益 ÷ 总投入」当年化，这会系统性高估（后期投入的钱几乎没参与上涨却摊薄了分母）。同一段行情，两种算法能差出十几个百分点——这是本站最想让大家看清的一件事。

相关系数

ρ = cov(X, Y) / (σ_X · σ_Y)

说明什么：两个标的同涨同跌的程度，是「分散化」这套说法的地基。

什么时候会骗人：三个陷阱：① 相关性不是恒定的，危机时会上升；② 低相关不等于好，一个长期下跌的资产也可能低相关；③ 短样本（不足约 250 个交易日）估出来的相关性极不稳定。

分散化比率

加权平均波动率 / 组合实际波动率

说明什么：大于 1 说明各资产没有完全同向，组合波动低于各自波动的加权平均。

什么时候会骗人：它衡量的是波动的减少，不是收益的改善。降低波动不等于提高收益，也不等于「更安全」——如果波动主要来自下跌，降低它确实是好事，反之则未必。

Beta 与 Alpha

对基准做线性回归：r_p = α + β·r_b + ε

说明什么：Beta 衡量跟随基准波动的幅度，Alpha 是剥离基准贡献后剩下的部分。

什么时候会骗人：两者都是**事后**统计量，换基准（沪深300 / 中证全指）结果就不同；而且 5 年以内的 Alpha 几乎无法与噪声区分。

跟踪误差

组合与基准收益差的年化标准差

说明什么：衡量组合偏离基准的程度，是评价指数产品的核心指标。

什么时候会骗人：跟踪误差接近 0 只说明「像基准」，不代表跑赢或风险更低；ETF 的跟踪误差还要叠加费率与买卖价差。

为什么必须用前复权价

前复权价 = 原始价 × 累计复权因子（越早的日期因子越小）

说明什么：把历史价格按分红除权调整到与今天可比的口径，这样算出来的收益才包含分红。

什么时候会骗人：用未复权价计算，会把每次分红除权当成本金亏损，长期下来会**低估**收益。本项目同时落库两种价格与复权因子，任何结论都能回溯口径。

风险贡献（成分 VaR）

贡献_i = w_i × (Σw)_i / σ_p × z，各项之和 = 组合 VaR

说明什么：把组合风险拆到每个标的上，看谁在真正制造波动——它常常和权重排序不一样。

什么时候会骗人：它用的是协方差矩阵，对尾部事件的刻画是正态近似的；某个标的平时波动小但危机时与其它标的一起跳，它的风险贡献会被低估。

折溢价率

折溢价率 = 二级市场收盘价 / 基金单位净值 − 1

说明什么：ETF 像股票一样在二级市场交易，价格可以高于（溢价）或低于（折价）它真实的净值。

什么时候会骗人：溢价买入等于多付钱：标的指数不涨不跌，溢价回落到正常水平就是一笔纯亏损。跨境 ETF 在额度紧张时溢价会明显放大。**但跨境品种要特别小心**：QDII 净值披露有滞后，它反映的是上一交易日境外市场收盘，所以算出来的「溢价」里有一部分是时滞造成的假象——不能直接当成你多付了那么多钱。

算术平均年化 vs 复合年化（CAGR）

算术年化 = 日收益均值 × 252；复合年化 = (末值/首值)^(1/年数) − 1

说明什么：两者之差就是**波动拖累**，近似等于 σ²/2。波动越大，差距越大。

什么时候会骗人：「平均年化收益」在各种宣传里通常指**算术平均**，它总是高于你实际拿到的复合收益。用 20% 波动率算，光这一项每年就能凭空多出约 2 个百分点——拿它去估算长期复利会系统性高估。

杠杆与强制平仓本组合可用的场内工具

2008 年海外机构用极低保证金持有巨额次贷敞口；A 股 2015 年用场外配资做了同一件事——机制完全一样。

维持担保比例 = 总资产 / 负债；跌破平仓线即被强制卖出

说明什么：杠杆让你用更少的本金持有更多资产，放大的是**同方向的收益与亏损**。

什么时候会骗人：杠杆不创造风险，它把风险**集中到同一个时刻释放**：价格下跌 → 补保证金 → 被迫卖出 → 价格继续下跌。所以杠杆牛市的顶部往往不是慢慢磨出来的，而是一起被平掉的。

流动性螺旋境外/银行间工具 · 不在你的可投范围

2008 年雷曼倒下时，大家都想卖、没人想买；2024 年 2 月的小盘股、2015 年的强平，都是同一回事。

价格 ↓ → 被动卖出 ↑ → 价格 ↓（自我强化的反馈回路）

说明什么：当卖出不再是因为「看空」、而是因为「必须卖」（补保证金、被赎回、产品敲入）时，价格会脱离基本面连续下杀。

什么时候会骗人：这种下跌**与估值无关**，所以「跌得多了所以安全」在螺旋里会失效。它也是分散化最脆弱的时刻——平时低相关的资产会同时被卖。

隐含波动率与期权价格本组合可用的场内工具

2020 年 3 月全球隐含波动率冲到历史极值，期权价格随之暴涨——那时候才想买保险，是最贵的时候。

期权价格 = 内在价值 + 时间价值（时间价值随隐含波动率上升而变贵）

说明什么：隐含波动率是市场**对未来波动的定价**，不是历史波动的记录。买期权＝买波动率，卖期权＝卖波动率。

什么时候会骗人：买保险看起来「最多亏权利金」，但长期持续买会不断被时间价值磨掉；危机中隐含波动率飙升让期权变贵，也就是说**你在最需要它的时候买最贵**。反过来，卖期权在多数时候稳定收钱，却会在极端行情里一次亏光——2008 年卖波动率的机构就是这么倒下的。

信用利差与 CDS境外/银行间工具 · 不在你的可投范围

2008 年雷曼与花旗的 CDS 利差飙升：市场用「保费」的价格，提前给违约概率定了价。

信用利差 = 公司债收益率 − 同期限国债收益率

说明什么：利差是市场对**违约概率与回收率**的定价。它比评级、比财报更早、更连续地反映市场判断。

什么时候会骗人：利差扩大既可能是基本面恶化，也可能只是流动性紧张——两者要分开。**并且要注意**：CDS 是境外/银行间市场的信用衍生品，国内个人投资者无法直接交易；本组合可用的最接近的观察对象是债券 ETF 与国债收益率曲线，而不是 CDS 本身。

汇率贡献

跨境 ETF 收益 ≈ 标的指数收益 + 汇率变动 + 溢价变动

说明什么：跨境资产的一部分涨跌与境内外市场无关，只来自汇率与溢价；把它拆出来才知道自己在赌什么。

什么时候会骗人：汇率既可能放大也可能抵消收益，而且方向会变。只看总收益会把汇率贡献误当成选股/选板块能力。

久期与利率敏感性

债券价格变动 ≈ -久期 × 收益率变动

说明什么：债券 ETF 的价格波动主要来自利率变化，久期越长，同样幅度的利率变动造成的价格冲击越大。

什么时候会骗人：久期不是固定值，会随剩余期限与利率水平变化；而且它对信用利差、流动性冲击完全无解释力。

Delta 与 Gamma

Delta = ∂V/∂S；Gamma = ∂²V/∂S²

说明什么：Delta 告诉你标的小幅变动时期权价值变多少；Gamma 告诉你**这个 Delta 自己变得多快**。

什么时候会骗人：Gamma 大意味着 Delta 不稳定：不做再对冲，一次较大波动就会让你的敞口偏离目标。而且 Gamma 与 Theta 是一对——买 Gamma 通常在付时间价值。

蒙特卡洛模拟

从拟合的收益分布中重复抽样出 N 条未来的净值路径

说明什么：把「一个点估计」变成「一个分布」：终值分布、达标概率、回撤深度分布。

什么时候会骗人：它只能复现**你假设的分布**。用历史正态分布去模拟，就永远模拟不出历史里没有过的极端事件；而且路径数不够时结果本身在抖，所以本项目强制展示收敛诊断。

对冲成本

对冲后收益 ≈ 组合收益 - 对冲比率 × 期货收益 - 基差成本 - 展期成本

说明什么：对冲不是免费的：股指期货长期贴水意味着每年要付出可观的确定性成本。

什么时候会骗人：只看「对冲后回撤变小」是片面的——成本会持续侵蚀收益，而且极端行情下基差可能瞬间扩大，对冲效果与回测差异很大。
